SKYBOOK - ONLINE FLIGHT RESERVATION SYSTEM

Open index.html in a browser.

This is a simple Internet Programming Lab practical project made using:
- HTML
- CSS
- JavaScript

Included pages:
1. Administrator User Login
2. Forgot Password
3. Search Flight
4. Book Ticket
5. Ticket Payment
6. My Ticket
7. Cancel Ticket
8. Customer Feedback
9. Admin Report
10. View Booking Status
11. Print Ticket
12. Admin Flight Management
13. Seat Inventory
14. User Management

Working demo features:
- Dropdown navigation menus
- Flight search by origin and destination
- Class filtering
- Flight availability display
- Dynamic Economy/Business seat dropdown
- Demo payment
- PNR generation/status
- Ticket printing
- Ticket cancellation
- Admin dashboard and reports

No backend or database is used.
