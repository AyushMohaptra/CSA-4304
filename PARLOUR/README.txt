BEAUTY PARLOUR APPOINTMENT BOOKING — LAB PROJECT

How to run:
1. Extract this ZIP file.
2. Open index.html in a browser.
3. Book an appointment by entering a name, service, stylist, date and time.
4. Open admin.html and log in to manage reservations or lock unavailable slots.

Features:
- Search services and view prices
- Book appointments with a stylist, date and time
- Prevent double-booking of a stylist/time and block locked slots
- Cancel appointments and view appointment status
- Manager can filter reservations by date, cancel/complete bookings, and lock time slots
- Demo payment selection (no real payment is processed)
- Submit feedback
- Registration demo

Note: This is a simple front-end project. Data is stored in browser localStorage. Real SMS/calls, emails, Stripe/PayPal, automatic unpaid cancellation, and secure authentication require a backend and are not implemented.
