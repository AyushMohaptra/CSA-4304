MEDCARE HOSPITAL APPOINTMENT BOOKING — LAB PROJECT

How to run:
1. Extract the ZIP file.
2. Open index.html in a browser.
3. Search doctors by name, specialty, or location.
4. Book an appointment and note the appointment ID.
5. Submit a check-in form using that ID.
6. Open admin.html to manage appointments and add doctors.
7. Open hospital.html to edit hospital details and open the Google Maps search link.

- Admin appointment management, statistics, and adding doctors
- Hospital details and location update

Note: This is a front-end demonstration using localStorage. It does not handle real patient data securely. Email/SMS reminders, real hospital integrations, and production authentication are not implemented. Do not enter real medical or sensitive personal information.
