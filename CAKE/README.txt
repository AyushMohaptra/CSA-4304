BUY A CAKE — INTERNET PROGRAMMING LAB PROJECT

Contents
- index.html: home page, cake search/filter, cart, place order, order history
- register.html: student registration
- login.html: student login and demo admin login
- admin.html: add/delete cakes and update order status
- css/style.css: responsive styling
- js/app.js: cake listing, search, filters, cart and orders
- js/auth.js: demo registration/login
- js/admin.js: product and order management

How to run
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Register a user, then log in through login.html.
4. Add cakes to cart and place a demo order. Enter a shipping address when prompted.
5. Open admin.html to add/delete cakes and update order status.

Notes
- This is a front-end lab demonstration. Data is stored in browser localStorage.
- Payment processing, email confirmation, real delivery tracking, image uploads, and secure server-side authentication are NOT implemented.
- Do not use real passwords or payment details. A production system requires a backend, database, password hashing, access control, and a real payment gateway.
